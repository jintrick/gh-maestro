# テストは実リポジトリを workspace として使わない

`workspace` として渡すパスは一時ディレクトリにする。リポジトリルート（`path.resolve(__dirname, '..')` 等）を渡さない。

スクリプトは渡された workspace の `.gh-maestro/` へ状態を書く。実リポジトリを渡すと、開発者が使用中のセッション状態を上書き・削除する。

実リポジトリの状態を参照する場合も、書き込み・削除を伴う関数に実リポジトリのパスを渡さない。参照が書き込みを誘発するなら、そのテストは書かない。
