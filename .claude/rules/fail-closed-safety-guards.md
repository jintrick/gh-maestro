# 外部コマンド依存の安全ガードはフェイルクローズにする

安全ガード（危険な操作を止めるためのチェック）が、外部コマンド（`git` 等）の実行結果に依存している場合、その検出自体が失敗した（コマンドが無い、例外を投げた等）ときは、警告して処理を継続するのではなく、`--force` 等の明示的なフラグなしでは中断する。

- 実障害: `scripts/install.js` に追加されたWIPブランチ検出ガードが、`git branch --show-current` の呼び出しを try/catch で囲んでいたが、catch パスが警告ログを出すだけで、その後 `~/.gh-maestro/` への破壊的な書き込み処理にそのまま進んでいた（PR #44 Review Manager指摘）。`git` がPATHに無い等でブランチ検出自体が失敗すると、未マージのfeatureブランチにいてもinstallが素通りし、そのガードが防ごうとしていた事故がそのまま再発する。
- 対策: 検出失敗は「安全と判定できない」ことを意味する。安全と確認できない場合は安全側（中断）に倒す。継続する場合は `--force` 等、呼び出し側の明示的な意思表示を必須にする。
