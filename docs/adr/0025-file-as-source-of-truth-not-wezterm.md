# 受け渡しはファイルを正本とし、WezTerm に依存しない

## 決めたこと

エージェント間の受け渡しは、ファイルを正本として受信側が読みに行く形にする。WezTerm への依存を新たに増やさない。通知に本文を載せない。

## なぜ

WezTerm の `send-text` で相手のセッションへ本文を注入すると、受信側の入力トークンをそのぶん消費する。通知が増えるほど全セッションの固定費になる。ファイルに置いて受信側が必要なときに読む形なら、読まなかった分のコストは発生しない。

またターミナルへの注入は、相手が生きていて画面を持っていることを前提にする。ヘッドレスで動くワーカーには届かず、届いたかどうかも確かめられない。ファイルなら存在を確認できる。

## 却下した案

通知に本文を含めて相手が読みに行く手間を省く案。受信側の入力トークンを常に消費するため採らなかった。この案は実際に提案して差し戻されている。
