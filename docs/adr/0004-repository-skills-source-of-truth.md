# リポジトリ内のスキルを正本にする

## 決めたこと

スキルの正本はリポジトリの `skills/` 配下とする。インストール済みのユーザー領域や生成されたエージェントディレクトリは直接編集しない。既定のエージェント設定を変えるときは `skills/agents.yaml` を更新し、実行可能な処理は `scripts/` に置く。スキル、スクリプト配布、エージェントの既定値を変更した場合は、変更をマージした後に `dev` ブランチからインストールする。

## なぜ

インストール済みのファイルはリポジトリから配布されるコピーであり、直接編集すると次の配布で失われる。正本をリポジトリに固定すれば、変更をレビューし、安定ブランチから同じ内容を配布できる。実行処理を `scripts/` に集めることで、スキルの説明と実装の所在を分けずに検証できる。

## 却下した案

- インストール済みコピーを直接編集して動作を直す案。レビュー可能な正本と配布結果が分離し、再インストールで変更が失われるため採らなかった。
- 各エージェントの生成先に個別の実装を置く案。同じ動作の修正を複数箇所へ反映する必要が生じ、配布時の不整合を生むため採らなかった。
- スキルディレクトリ内へ実行処理を隠す案。スクリプトの配布・検証経路から外れ、正本の範囲が不明確になるため採らなかった。
