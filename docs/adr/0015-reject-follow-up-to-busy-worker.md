# 作業中のワーカーへの追従依頼を拒否し無期限に待たない

## 決めたこと

作業中のワーカーに対する追従依頼は送信前に拒否する。報告後に終了しない常駐プロセスには、異常を通知する。作業中のワーカーが空くことを無期限に待つ配送経路は作らない（Issue #263・#264）。

## なぜ

作業完了後もワーカーが居座ると、待ち続ける配送は上限も通知もなく滞留する。orchestratorからは正常に作業中なのか、報告後に異常終了しないのかを見分けられず、待ち続けるだけで異常が可視化されない。送信前に拒否し、居座りは通知へ変換すれば、次の判断をorchestratorへ戻せる。

## 却下した案

- ワーカーが空くまで追従依頼をキューで待たせる案。終了しないワーカーで無期限に滞留するため採らなかった。
- 作業中でもすぐ追従依頼を送り込む案。実行中の作業へ予期しない入力を混ぜ、役割と工程の境界を壊すため採らなかった。
- 報告後に居座るプロセスを無通知のまま待ち続ける案。orchestratorが異常を検知できないため採らなかった。
