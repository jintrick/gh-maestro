# Review Managerの判断面とNode.jsの実行面を分離する

## 決めたこと

Review Managerはレビュー観点、調査計画、指摘の意味を判断する。Node.jsの決定論的な実行面は、定義された計画の実行、結果の検証、重複排除、アンカー解決、GitHubへの公開を担う。判断と実行を同じモデルの自由な処理に委ねない（Issue #196・#198）。

## なぜ

モデルにレビュー観点の実行と結果の公開まで自由に行わせると、サブエージェントが何を実施したかを検証できず、全件テストや同じ調査の繰り返しでクォータを消費する。判断をReview Managerに、反復可能な検証と公開をNode.jsに分ければ、計画どおりに実行されたかを機械的に確認でき、レビューの判断と公開処理の責任も分かれる。

## 却下した案

- 各レビュー用モデルに計画、実行、公開をすべて自由に任せる案。実行範囲と結果を再現できず、クォータの浪費を防げないため採らなかった。
- Node.jsがレビューの妥当性や指摘の優先順位まで決める案。決定論的な処理では表現しにくい設計上の判断を機械へ移すため採らなかった。
