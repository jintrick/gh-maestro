# 作業開始前に最近の状況とインストール済みの挙動を確認する

## 決めたこと

診断やコード・設定の状態を断定する前に、直近のマージ済みPRとIssueの動きを確認する。インストール済みコピーが古いと判断するときは、ファイル差分の見た目ではなく、対象の関数などの実際の挙動と、関連コミットのマージ時刻およびファイルの更新時刻を確認する。

## なぜ

新しく参加した人と同じ開始条件をそろえないと、直近の修正や明示的な見送りを知らないまま、既に解決した問題を再調査する。特に Windows では改行、FIFO、プロセス置換の影響で、インストール済みファイルとリポジトリの差分が実際より大きく見えることがある。挙動を実測せずに古いと断定すると、存在しない不具合の修正に人間とワーカーの時間を使う。

## 却下した案

- 現在のファイルだけを読んで最近のIssue・PRを確認せずに診断を始める案。既に行われた修正や見送りの理由を取りこぼすため採らなかった。
- 差分の表示や印象だけでインストール済みコピーの鮮度を判断する案。環境に依存する表示上の差を実際の挙動と取り違えるため採らなかった。
