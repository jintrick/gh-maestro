# レビュー観点を審査対象外の正本から読む

## 決めたこと

Review Managerが使うレビュー観点の定義は、審査対象のPRやその作業ツリーから読まない。対象PRから独立した配布済みの正本から読み込み、正本の配布・検証経路を維持する（Issue #309・#310）。

## なぜ

審査されるPRから観点定義を読むと、PR自身が自分を審査する基準を変更できる。観点ファイルを空にするなどの変更が、審査を緩める手段になる。対象外の正本を読むことで、レビュー対象とレビュー基準の責務を分離し、観点が変更されたときも配布元の変更として確認できる。

## 却下した案

- 審査対象PRの観点ファイルをそのまま読む案。PRが自分の審査基準を差し替えられるため採らなかった。
- 各PRへ観点定義をコピーして審査する案。コピーの改変を検出できず、正本と対象の境界も失うため採らなかった。
- ファイル名の不一致や空ファイルだけを検出し、対象PRから読む案。正しい名前で緩い基準に差し替える経路を防げないため採らなかった。
