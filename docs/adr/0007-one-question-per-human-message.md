# 人間への質問を一発言一問に分ける

## 決めたこと

一つの発言の末尾に置く質問は一つだけにする。選択肢や説明と不可逆な操作の承認を同じ発言に含めず、先に選択肢の回答を得てから、対象と操作を明示した承認を別の発言で求める。短い「はい」や番号だけの返答は、直前の発言に一つの質問しかない場合に限り、その質問への回答として扱う。質問数は疑問符の数ではなく、回答で実行される操作の数で判断する。

## なぜ

「どちらを選ぶか」と「今実行してよいか」を同じ発言で尋ねると、短い返答が不可逆な操作への承認として誤読される。実際に、一言の返答で意図していない停止操作が走る状態が生じ、同じ問題に対する規則の追記が二度必要になった（commit `88d5b60`、`2c01151`）。長い提案や複数の操作を一つの yes/no で承認させると、人間が読んだ範囲と実行への同意の範囲も一致しない。

## 却下した案

- 選択肢の回答と不可逆な操作の承認を一つの質問にまとめる案。短い返答の対象が曖昧になり、意図しない操作を実行し得るため採らなかった。
- 疑問符が一つなら一つの質問とみなす案。複数の操作を一つの文に隠せるため、承認対象の数を保証できないため採らなかった。
- 長い提案全体に対して「はい」だけを求める案。人間が全文を読んだことを前提にしてしまい、承認範囲を明確にできないため採らなかった。
