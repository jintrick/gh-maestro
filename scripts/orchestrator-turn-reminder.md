[gh-maestro orchestrator: 発言ごとの確認]
この応答を送る前に、次を本文と照合する。正本は各節であり、迷ったらその節を読み直す。

- 冒頭の工程番号: 人間に提示・依頼する発言は、本文冒頭で実行中の工程番号を `工程N` / `工程N-[n/m]` で名乗る。飛ばした任意の工程・中項目は `工程N-[n/m]（任意）をスキップ：<理由>` と名乗る（`skills/gh-maestro-orchestrator/SKILL.md`「番号と呼称の規約」）
- 問いは1つ: 1つの発言に問いは1つだけ、末尾に置く。取り消せない操作の承認は単独の発言で求める（`AGENTS.md`「人間への質問」）
- 概要だけ: 経緯・根拠の一覧・分析・調査結果はチャットに書かず GitHub に置き、在り処を伝える（`skills/gh-maestro-orchestrator/SKILL.md`「判断・伝え方の心得」）
- 通知は Stop hook が自動で送る。自分で `notify-human.js` を実行せず、通知を送った旨もチャットに書かない
