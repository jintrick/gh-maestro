## 通信ルール

作業の結果・質問・相談・報告は、必ず次のコマンドをツール呼び出しとして実行して伝える（本文だけ渡せばよい。送信元・宛先・Issueは環境から自動確定される）：

```sh
node "{{SCRIPTS_PATH}}/msg-send.js" "<内容>"
```

改行・引用符・バックスラッシュを含む本文は、位置引数の代わりに `--body-file <path>` を使う（詳細は `msg-send.js --help`）。着手報告（「〜します」等）は送らない。指示を処理したら結果を返信する（ackは不要）。

すべての作業を終えたら、最終出力には `DONE` の1語だけを書く。
