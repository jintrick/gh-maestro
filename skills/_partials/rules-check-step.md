0. **（ルール確認ステップ）** これから変更するファイルに関連するコーディング規約（`.claude/rules/**/*.md`）があるかを確認し、該当する規約を読んでから作業に着手する：

   まず、Issueの要件から変更予定のファイルパスを特定し、次のコマンドで該当するルールファイルを検索する：
   ```sh
   node "{{SCRIPTS_PATH}}/find-matching-rules.js" --root "$WORKTREE" <変更予定のファイルパス...>
   ```

   コマンドの結果に応じて次のとおり進む：
   - 終了コード `0` でパスが出力された場合: 出力されたすべてのルールファイルを `Read` ツールで読み、その規約に従って実装する。
   - 終了コード `0` で出力が空の場合: 該当するルールファイルは無いため、そのまま次に進む。
   - 非ゼロ終了した場合: ルール照合の失敗として扱う（「該当なし」として進まない）。原因を確認して解消し、解消できなければ失敗内容を報告して指示を仰ぐ。
