# Correctness / API Contract

目的: diffが新規に呼び出す・呼び出し方を変えるAPI(言語標準ライブラリ・外部コマンド・
フレームワークのフック/ライフサイクル規約を含む)について、そのAPI側の使用契約への
違反を探す。gh-maestroの実装ではなく、依存先が課す規約を破っていないかを確認する。

## 外部参照の裏取り

標準API・外部コマンド・フレームワークの挙動を記憶だけで判定してはならない。
確信がなければ公式ドキュメント、`--help`、型定義、`docs/rag/`配下のローカル文書で裏取りする。
裏取りできなかった場合はfindingにせず、確信が持てる範囲のみ報告する。

## 禁止

- 裏取りしていない挙動の推測に基づく指摘
- diff範囲外の一般的な設計指摘
- severity判定根拠を明示できない推測指摘
